How Stroke works

  • Discovery-first onboarding – placement optional to start
  • Adaptive quests per topic, hints, confidence checks
  • XP, streaks, hearts, coins, mistake notebook, flashcards
  • Interactive maths models + graph visualizer
  • Code Arena – runnable JS in time-limited Web Worker
  • Periodic table 118 + Three.js atom views
  • Three.js molecule explorer
  • Three.js solar-system with missions, gravity, orbit comparison, rocket lab
  • PWA offline + cloud sync opt-in via recovery key

Sync: generate a cryptographically random recovery key in browser. Copy it and restore on another device. Anyone with key can access that learner's progress. API is same-origin /api – no localhost calls from hosted site. 409 on stale revision to avoid overwriting newer progress.

Storage: PostgreSQL when DATABASE_URL set, local JSON file fallback for dev only. Production requires DATABASE_URL because cloud filesystem may not persist.
